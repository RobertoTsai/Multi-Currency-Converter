# 快速驗證指南 (Quickstart & Verification Guide)

**功能分支**: `001-settings-panel`

本文件指引如何以手動方式載入並驗證「設定面板」功能之正確性。

---

## 1. 準備工作 (Prerequisites)

1.  確保已安裝 Google Chrome 或 Chromium 核心之瀏覽器。
2.  專案原始碼已拉取至本地，且設定與核心代碼皆位於 `Extension/` 目錄中。
3.  詳細的資料欄位定義與儲存格式可參閱 [data-model.md](./data-model.md) 及 [storage-contract.md](./contracts/storage-contract.md)。

---

## 2. 載入擴充功能 (Loading the Extension)

1.  開啟 Chrome 瀏覽器，在網址列輸入 `chrome://extensions/` 並按下 Enter。
2.  在右上角開啟「**開發者模式**」(Developer mode) 開關。
3.  點擊左上角的「**載入未打包項目**」(Load unpacked)。
4.  選取本專案的 `Extension/` 資料夾（路徑包含 `manifest.json` 所在的目錄）。
5.  確認「Multi-Currency Converter」擴充功能已成功載入且無任何錯誤紅字。

---

## 3. 手動驗證情境 (Manual Verification Scenarios)

### 情境 1: 設定入口與面板切換
1.  點擊 Chrome 工具列上的擴充功能圖示，開啟「Multi-Currency Converter」popup 視窗。
2.  確認在畫面右上角（或顯眼位置）有齒輪圖示的「設定」按鈕。
3.  點擊「設定」按鈕，確認：
    -   原本的貨幣清單與新增按鈕消失。
    -   設定畫面平滑顯示。
    -   設定畫面左上角有「返回」按鈕。
4.  點擊「返回」按鈕，確認回到主換算畫面，且原本的金額與排序完全沒有變動。

### 情境 2: 數字格式自訂與即時預覽
1.  進入設定畫面。
2.  在「小數點符號」下拉選單選擇 `.`，在「千分位分隔符」選擇 `,`。
3.  觀察預覽區塊的 `12345.67` 是否正確顯示為 `12,345.67`。
4.  在「小數點符號」下拉選單選擇 `,`，在「千分位分隔符」選擇 `.`。
5.  觀察預覽區塊是否變更為 `12.345,67`。
6.  點擊返回按鈕回到主畫面，確認所有貨幣金額（如 `USD 100` 或 `TWD 3,000`）的分隔符皆已變更為設定樣式。

### 情境 3: 格式衝突自動更換
1.  進入設定畫面。
2.  當前小數點設為 `.`，千分位設為 `,`。
3.  點選小數點為 `,`，確認：
    -   「千分位分隔符」選單自動跳轉為 `.` 或其他非 `,` 的選項。
    -   預覽區正常顯示為 `12.345,67`。

### 情境 4: 介面語言變更與持久化
1.  進入設定畫面。
2.  在「語言設定」下拉選單中選擇「繁體中文」。
3.  確認設定面板上的文字（如「小數點格式」、「預覽」、「返回」）立即翻譯為繁體中文。
4.  關閉擴充功能 popup 視窗。
5.  重新開啟 popup，確認直接呈現繁體中文介面。
6.  再次進入設定面板，確認先前設定的小數點與千分位設定值依然正確保留。

### 情境 5: 錯誤數值 Fallback 與離線測試
1.  開啟 Chrome 開發者工具（在 popup 視窗上點擊右鍵選擇「檢查」）。
2.  切換至「Application」分頁，在「Local Storage」與「Sync Storage」中手動將 `userSettings` 修改為損壞的非 JSON 字串或非法值。
3.  重新開啟 popup，確認擴充功能依然能正常渲染啟動，且系統會預設使用 `.` 作為小數點、`,` 作為千分位。
4.  關閉網路連線，開啟 popup，確認即使匯率 API 載入失敗，本地已儲存的設定格式依然正常作用於既有快取的金額顯示上。
